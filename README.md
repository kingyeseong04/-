# Candle Tick Replay — 과거 캔들 실시간 매매 시뮬레이터

해외 거래소처럼 가격이 **틱 단위로 실시간으로 움직이는** 화면을, **과거 캔들 데이터** 위에서 재생해 주는 도구입니다. 캔들이 자라나는 동안 **롱/숏 포지션을 잡고, 틱마다 미실현 손익·포지션·청산가·잔고가 실시간으로 갱신**됩니다. 일종의 "리플레이 백테스트" 트레이너예요.

## 핵심 아이디어

캔들은 OHLC(시가/고가/저가/종가)만 저장하므로 캔들 내부의 실제 체결 순서는 알 수 없습니다. 이 도구는 다음 조건을 만족하는 **그럴듯한 틱 경로를 합성**합니다.

- 시가에서 시작해 종가로 정확히 끝남
- 고가와 저가를 반드시 한 번씩 찍음
- `[저가, 고가]` 범위를 절대 벗어나지 않음
- 그 사이는 브라운 브리지(Brownian bridge) 기반 랜덤워크로 자연스럽게 흔들림

`js/tickEngine.js`에 구현돼 있습니다.

## 실행 방법

별도 빌드가 필요 없는 순수 정적 웹앱입니다. 로컬 서버로 열면 됩니다.

```bash
# 아무거나 하나
python3 -m http.server 8000
# 또는
npx serve .
```

브라우저에서 `http://localhost:8000` 접속.

> 처음 열면 **네트워크 없이도** 합성 데모 데이터가 자동 로드돼 바로 재생할 수 있습니다.

## 데이터 소스

화면 하단 컨트롤에서 선택합니다.

거래소는 **바이낸스 하나로 고정**이며 실제 시장 데이터를 사용합니다. (거래량은 표시하지 않고 캔들만 그립니다.)

| 방법 | 설명 |
|------|------|
| **Load** | 심볼 / 인터벌(`5m·15m·1h·4h·1d`) / **시작 날짜·시각** / 캔들 개수를 정하면 바이낸스 공개 API에서 그 시점부터의 과거 캔들을 받아옵니다. 날짜를 비우면 최신 구간을 가져옵니다. (브라우저에서 직접 호출하므로 네트워크 접근이 필요) |
| **CSV** | 보유한 OHLC CSV 파일을 업로드합니다. 헤더(`time,open,high,low,close`)가 있으면 컬럼명으로, 없으면 `openTime,open,high,low,close,...` 순서로 자동 파싱합니다. (거래량 컬럼이 있어도 무시) |
| **Demo** | 오프라인 합성 캔들. 네트워크가 막혀 있어도 동작합니다. |

## 조작법

- **Play / Pause** — 재생/일시정지 (단축키 `Space`)
- **Restart** — 같은 데이터로 처음부터 다시
- **Speed** — 틱 간격(ms)
- **Ticks** — 캔들 하나를 몇 개의 틱으로 쪼갤지
- **Long (L) / Short (S)** — 현재 틱 가격으로 진입
- **Close All (C) / Close 50%** — 청산

`Margin`(증거금)과 `Leverage`(레버리지)로 포지션 크기를 정합니다. (명목 = 증거금 × 레버리지)

## 매매 모델 (`js/trading.js`)

- 순포지션(netting) 방식: 같은 방향이면 평단 가중평균, 반대 방향이면 부분/전체 청산 후 남으면 반대로 플립
- 미실현/실현 손익, 자산(equity), 가용 증거금 실시간 계산
- 테이커 수수료 0.04% 반영
- 고립 증거금 가정의 추정 청산가 계산 및 차트 표시(진입가·청산가 라인)
- 자산이 유지증거금 아래로 떨어지면 자동 청산

## 파일 구조

```
index.html        레이아웃 / 마크업
css/styles.css     다크 거래소 스타일 테마
js/tickEngine.js   캔들 → 틱 경로 합성
js/dataSource.js   바이낸스 / CSV / 데모 데이터 로더
js/trading.js      포지션·손익·청산 엔진
js/chart.js        lightweight-charts 래퍼 (실시간으로 자라는 캔들)
js/app.js          전체 오케스트레이션 / 재생 루프 / UI
```

> ⚠️ 이 도구는 교육·연습용 시뮬레이터입니다. 합성 틱은 실제 체결 흐름이 아니며, 투자 조언이 아닙니다.
