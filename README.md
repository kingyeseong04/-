# Bybit-style Replay — 과거 캔들 실시간 매매 연출

**바이비트(Bybit) 거래소 UI를 그대로 재현**한 화면 위에서, **과거 캔들 데이터**를 틱 단위로 실시간처럼 재생하는 도구입니다. 과거 시점을 골라 그 순간 실시간으로 트레이딩하는 것처럼 **연출(영상용)**하는 것이 목적입니다. 캔들이 자라나는 동안 **롱/숏 포지션을 잡고, 틱마다 미실현 손익·포지션·청산가·잔고가 실시간으로 갱신**됩니다.

바이비트 UI 요소: 상단 시세바(Mark·24H High/Low·펀딩 카운트다운), **미실현 손익·Equity·Available 패널**(원화 환산 포함), 레버리지 칩, 초록 Buy/Long·빨강 Sell/Short 버튼, **TP/SL 자동 청산**, 하단 Positions/Trade History 탭. 차트는 바이비트가 실제로 쓰는 것과 같은 TradingView(lightweight-charts)로 그립니다.

> 차트 라이브러리(lightweight-charts)는 `js/vendor/`에 포함되어 있어 **오프라인/네트워크 차단 환경에서도** 동작합니다.

### TradingView와 정확히 맞추기

- **거래소 = Bybit 무기한(.P)**: 데이터는 Bybit v5에서 받아옵니다. (브라우저에서 Bybit이 막힌 환경에서는 자동으로 바이낸스 `fapi` 무기한으로 폴백하고, 상태바에 `⚠ → Binance`로 알립니다.)
- **로컬 시간축**: 차트 시간축·크로스헤어를 보는 사람의 **로컬 타임존(예: KST)**으로 표시해, TradingView(로컬 시간 표시)와 캔들이 정렬됩니다. (UTC로 그리면 9시간 어긋나 다른 캔들처럼 보임)
- **실제 캔들 내부 움직임**: 재생 구간의 **더 낮은 타임프레임(5m→1m, 1h→1m, 4h→5m, 1d→15m)** 실제 캔들을 받아와 캔들 내부를 채웁니다. 즉 재생 중 오르락내리락이 **실제 시장 틱에 근접**합니다(상태바에 `real ticks ✓`). 서브 데이터를 받지 못한 경우에만 합성 틱으로 폴백합니다.
- Bybit이 브라우저에서 막힌 환경(CORS·지역 차단)에서는 자동으로 바이낸스로 폴백하고, 상태바에 `⚠ ... → Binance`로 알립니다.

## 핵심 아이디어

캔들은 OHLC(시가/고가/저가/종가)만 저장하므로 캔들 내부의 실제 체결 순서는 알 수 없습니다. 이 도구는 다음 조건을 만족하는 **그럴듯한 틱 경로를 합성**합니다.

- 시가에서 시작해 종가로 정확히 끝남
- 고가와 저가를 반드시 한 번씩 찍음
- `[저가, 고가]` 범위를 절대 벗어나지 않음
- 캔들 내부에 여러 개의 웨이포인트를 두어 **여러 번 오르락내리락(반전)** 하고, 그 사이는 브라운 브리지(Brownian bridge)로 자연스럽게 흔들림 → 포지션 손익도 캔들 동안 실시간으로 출렁임 (예: 60틱 5분봉이면 캔들당 ~30회 방향 반전)

`js/tickEngine.js`에 구현돼 있습니다.

## 실행 방법

별도 빌드가 필요 없는 순수 정적 웹앱입니다. 로컬 서버로 열면 됩니다.

```bash
# 아무거나 하나
python3 -m http.server 8000
# 또는
npx serve .
```

브라우저에서 `http://localhost:8000` 접속.

## 데이터 불러오기

화면 하단에서 **심볼 · 시간봉(`15m·1h·4h·1d`) · 시작 날짜·시각 · 앞뒤 캔들 개수**를 정하고 **Load**를 누릅니다. 심볼은 전부 **Bybit 무기한 선물**이라 모두 실제 틱을 지원합니다: `BTCUSDT.P · ETHUSDT.P · SOXLUSDT.P · TSLAUSDT.P · COHRUSDT.P · ALABUSDT.P · DRAMUSDT.P · XAUUSDT.P · SAMSUNGUSDT.P`. TradingView식 `.P`는 자동으로 제거해 Bybit 무기한으로 조회합니다. 지정한 날짜를 중심으로 **앞/뒤 캔들 개수(각 최대 1000, 기본 100)** 만큼 **Bybit v5** 공개 API에서 받아옵니다. (거래량은 표시하지 않고 캔들만 그립니다.)

- **날짜는 필수**입니다 — 과거 특정 시점에서 실시간처럼 재생하는 게 목적이라 항상 날짜 기준으로 동작합니다.
- **폴백 사슬**: Bybit이 브라우저에서 막히면(CORS·지역 차단) → 바이낸스 무기한(`fapi`) → 바이낸스 현물(`api`, CORS가 확실한 최후 수단) 순으로 자동 시도합니다. 실제로 데이터를 준 곳이 화면에 표기됩니다.
- 셋 다 실패하면 차트 가운데에 **에러 메시지**가 크게 표시됩니다(원인 포함).
- (브라우저에서 거래소 API를 직접 호출하므로 네트워크 접근이 필요합니다.)

## 영상 녹화용 클린 모드

차트를 영상 소스로 쓸 수 있도록, **차트만 전체화면으로** 보여주는 클린 모드가 있습니다.

- 하단 **`⛶ Clean`** 버튼 또는 **`F`** 키 → 트레이딩 패널·컨트롤바를 모두 숨기고 차트만 화면을 꽉 채웁니다(가능하면 브라우저 전체화면도 함께). **`Esc`** 로 빠져나옵니다.
- 창 크기에 맞춰 **반응형**이라, 녹화할 창을 16:9(가로)나 9:16(세로)로 맞추면 그 비율대로 차트가 채워집니다.

차트는 트레이딩뷰와 동일하게 보이도록 다음 요소를 포함합니다.

- 배경 **심볼 워터마크**(예: `BTCUSDT · 1h`)
- **좌상단 OHLC 범례** — 심볼·인터벌·거래소 + O/H/L/C 값과 등락률(상승/하락 색)
- **현재가 점선 라인 + 가격축 라벨**(캔들 방향 색)
- 트레이딩뷰 최신 기본 캔들색(상승 `#089981` / 하락 `#f23645`), Trebuchet MS 폰트, 동일한 그리드·크로스헤어 톤

## 조작법

- **Play / Pause** — 재생/일시정지 (단축키 `Space`)
- **Restart** — 같은 데이터로 처음부터 다시
- **배속(Speed)** — **실시간 대비 배속**입니다. `1×`면 1봉이 실제 봉 길이만큼(예: 1분봉=60초), 배속을 올릴수록 빨라집니다(최대 3600×). 라벨에 **현재 시간봉 기준 1봉이 몇 초/분에 만들어지는지**(`N× · 1봉≈X초`) 자동 표시됩니다.
- **레버리지** — `1×`~`125×` (주문 패널 슬라이더).
- **시작 자본 (USDT)** — 주문 패널에서 시작 잔고를 직접 정합니다.
- **재생 중에는 시작 자본·배속·틱 설정이 잠깁니다** — 값을 바꾸려면 일시정지(Space) 후 변경하고 다시 재생하세요.
- **배속 직접 입력** — 슬라이더 옆 숫자칸에 배속을 직접 입력(1~3600). 슬라이더와 자동 동기화.
- **🔒 고정** — 현재 생성 중인 봉에 차트를 고정(기본 On). 마우스로 차트가 움직이지 않아 녹화에 좋습니다. 끄면 자유롭게 이동/확대.
- **💰 손익** — 미실현 손익을 차트 위에 크게 표시(영상용). 드래그로 위치 이동.
- **💵 잔고** — 지갑 잔고(Wallet Balance)를 크게 표시. 드래그로 위치 이동.
- **TP / SL** — 주문 패널에서 익절가(TP)·손절가(SL)를 입력하면 차트에 라인이 표시되고, 재생 중 가격이 도달하면 **자동 청산**됩니다.
- **환율 (₩/USDT)** — 주문 패널에서 환율을 직접 입력하면, 손익·잔고 오버레이와 패널에 **한화(₩) 환산액이 자동 표시**됩니다.
- **📈 지표** — 지표 On/Off + 설정:
  - **볼린저밴드**: 기간(기본 20)·승수(기본 2)
  - **일목균형표**: 전환(9)·기준(26)·선행B(52)·선행이동(26). 구름(선행스팬 A/B 사이)까지 채워지고 미래로 투영됩니다.
  - 둘 다 **OHLC만으로 계산(거래량 불필요)**. 날짜 로드 시 지표 계산용 이력(앞 130봉)을 함께 받아와 로드 직후 바로 표시됩니다.
- **순서** — `① 심볼·시간봉·날짜 선택 → ② Load → ③ Play`. 데이터를 불러오기 전에는 Play/Restart가 비활성화되고, 재생 중에는 시작 자본·배속이 잠깁니다(일시정지 후 변경).
- **시간봉 자유 전환** — 같은 심볼일 때:
  - **날짜를 그대로 두고 시간봉만 바꿔 Load** → **현재 재생 시점에서, 포지션·잔고·레버리지 그대로 이어서** 재생 (`포지션·잔고 유지 (이어서)`). 5분봉이 너무 짧으면 1시간봉으로 갈아타 계속 진행하는 식.
  - **날짜를 바꿔 Load** → 그 새 시점으로 이동. 잔고·레버리지는 유지하되 열려 있던 포지션은 현재가로 정산됩니다.
  - **심볼 변경 / Restart** → 시작 자본으로 초기화.
- **✏️ 선 / 📏 자 / 🧲 마그넷** — 차트 위 드로잉 도구:
  - **선**: 드래그로 추세선을 그림(여러 개 유지). 캔버스 **더블클릭 = 전체 삭제**.
  - **자**: 드래그한 구간을 바이비트식 측정 상자로 표시 — **상승=파랑 / 하락=빨강**, `가격차 (%) 틱수 / N bars, 시간`.
  - **마그넷**: 켜면 그리는 점이 가장 가까운 캔들의 **O/H/L/C 값에 스냅**됩니다.
  - 클린 모드에서도 좌하단 플로팅 툴바로 사용할 수 있습니다.
- **진입가 지정** — 주문 패널의 "진입가 지정" 칸에 값을 넣으면 **그 가격에 진입**합니다(비우면 현재가). 예: 현재가 120인데 100에 롱을 누르면 즉시 +20% 상태로 잡힙니다(연출용).
- **자동 환율** — 로드 시 지정한 **날짜 기준 USD/KRW 환율**(ECB/frankfurter → 실패 시 Yahoo `KRW=X`)을 자동으로 받아 채우고, 환율칸 옆에 그날 환율·출처를 작게 표시합니다. 직접 수정도 가능.
- **Long (L) / Short (S)** — 진입가 지정 시 그 가격, 아니면 현재 틱 가격으로 진입
- **Close All (C) / Close 50%** — 청산

`Margin`(증거금)과 `Leverage`(레버리지)로 포지션 크기를 정합니다. (명목 = 증거금 × 레버리지)

## 매매 모델 (`js/trading.js`)

- 순포지션(netting) 방식: 같은 방향이면 평단 가중평균, 반대 방향이면 부분/전체 청산 후 남으면 반대로 플립
- 미실현/실현 손익, 자산(equity), 가용 증거금 실시간 계산
- 테이커 수수료 0.04% 반영
- 고립 증거금 가정의 추정 청산가 계산 (차트에는 진입가 라인만 표시, 청산가 라인은 표시하지 않음)
- 자산이 유지증거금 아래로 떨어지면 자동 청산
- 차트 위 포지션 라벨은 바이비트와 동일: `[P&L ±값(어두운 박스·흰 글씨)] [사이즈(사이드색 채움)] [⇅ 반전] [✕ 청산]`, 전체를 사이드색(롱 초록/숏 빨강) 테두리로 감쌈. `⇅`는 포지션을 반대 방향·동일 수량으로 반전.

## 네온 선 연출 도구 (`paint.html`)

차트 **캡처 이미지 위에 점을 찍어** 지지·저항선이나 돌파 화살표를 그리고, 그 선이 **네온으로 그려지는 애니메이션**을 영상으로 뽑는 별도 페이지입니다. 같은 사이트의 `/paint.html` 경로로 열립니다. 거래소 API를 쓰지 않아 **네트워크 없이** 동작하고, 올린 이미지는 브라우저 밖으로 나가지 않습니다.

- **도구 4종** (`Q` 선 · `W` 정원 · `E` 타원 · `R` 네모)
  - **선**: 클릭한 순서대로 이어지는 직선(곡선 없음). `Shift`로 수평·수직·45° 고정, 수평에서 몇 px 이내면 자동으로 평평하게 맞춰집니다. **화살표**를 켜면 화살촉이 처음부터 펜 끝에 붙어 목표로 날아갑니다.
  - **도형**: 두 번 클릭해 대각선 양 끝을 잡으면 완성됩니다. **정원**은 어떻게 끌든 항상 완전한 원, **타원**은 가로세로 자유(`Shift`면 정원). 네모도 `Shift`면 정사각형. 다음 클릭 위치는 점선으로 미리 보입니다.
- 도형도 선과 **똑같이 네온으로 그려지는 애니메이션**이 붙습니다. 내부적으로 원·네모를 촘촘한 폴리라인으로 펼쳐 선과 같은 경로를 타기 때문에, 이징·베이크·녹화가 전부 같은 코드로 동작합니다. 원은 12시에서 시계방향으로 그려집니다.
- **네온 렌더링**: 같은 경로를 폭을 키워가며 낮은 알파로 여러 번 겹쳐 그린 뒤(가산 합성) 흰색 심지를 얹습니다. `shadowBlur`로 큰 헤일로를 만들면 프레임이 밀려 녹화가 깨지므로 쓰지 않습니다.
- **재생**: 획이 순서대로 그려집니다. 긴 선일수록 오래 걸리고, **획 간 대기**로 나레이션에 맞춰 뜸을 들일 수 있습니다.
- **가감속(이징)**: 획마다 따로 지정합니다. `Cubic Out`(기본, 도착하며 감속 — 지지·저항선) · `Cubic In`(최고 속도로 끝 — 화살표) · `Circular`(양끝 느리고 중간이 빠름 — 긴 추세선) · `Linear`. 진행도는 획 전체 길이에 걸쳐 이징되므로 꺾인 선에서도 모서리마다 끊기지 않고 이어집니다.
- **색상**: 빨·노·초 고정 3색 + 직접 지정(브라우저 기본 색상 선택기, 폰에서는 OS 선택기). 옆의 HEX 칸에 `#FF2D95` 같은 코드를 바로 붙여넣을 수 있습니다.
- **녹화**: `⏺ 녹화` → 재생을 캡처해 webm으로 자동 저장. **배경끄기**로 녹화하면 검정 위 네온만 남아, 편집 프로그램에서 **스크린(Screen) 블렌드**로 원본 영상 위에 그대로 얹을 수 있습니다.
- 비율은 `3:4`(기본) · `9:16` · `1:1` · `4:5` · `16:9`. 점은 정규화 좌표로 저장돼 비율을 바꿔도 상대 위치가 유지됩니다.
- **전체화면**: 우하단 `⛶` 또는 `F`. 나갈 때는 **우상단 `✕` 버튼**이나 `Esc` — `✕` 버튼은 몇 초 뒤 흐려지지만 사라지지는 않아, 키보드가 없는 화면에서도 항상 빠져나올 수 있습니다.
- 조작법 전체는 페이지 우하단 `?` 버튼에 있습니다.

> 캔버스 녹화(`MediaRecorder`)는 **데스크톱 Chrome** 기준입니다. iOS 사파리 등에서는 그리기만 하고 녹화는 화면 녹화로 대신하세요.
